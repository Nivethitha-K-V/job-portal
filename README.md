AI Job Portal

AI Job Portal is a web-based recruitment platform developed using Python and Django. It connects job seekers and recruiters through a single platform while providing AI-assisted features such as Resume Analysis and Skill Gap Analysis to improve the recruitment process.

Project Features

- User Registration and Secure Login
- Job Seeker Profile Management
- Recruiter Company Profile Management
- Job Posting and Management
- Job Search and Application
- Resume Analysis
- Skill Gap Analysis
- Application Tracking
- Admin Management

Technology Stack

Frontend:
- HTML
- CSS
- Bootstrap
- JavaScript

Backend:
- Python
- Django

Database:
- SQLite

Libraries:
- Pillow
- PyPDF2

Project Workflow

Job seekers register, complete their profile, upload their resume, analyze their resume, search for jobs, and apply for suitable positions. Recruiters create company profiles, post job openings, manage applications, and review candidate profiles through the platform.

How to Run

```bash
git clone https://github.com/Nivethitha-K-V/job-portal.git
cd job-portal
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
